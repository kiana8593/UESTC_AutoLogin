UESTC 校园网自动登录  v1.0.0  使用说明
======================================================================

一句话：双击 UESTC-AutoLogin.exe，填一次学号和密码，以后掉线自动重连，
还可以开机就跑、连 Windows 都不用登录。

程序里已经自带 Python 和所有依赖，不需要装 Python，也不需要装 conda。


----------------------------------------------------------------------
一、第一次使用（3 步）
----------------------------------------------------------------------

1) 把 UESTC-AutoLogin.exe 放到一个固定的文件夹里，例如

       D:\APPs\UESTC-AutoLogin\UESTC-AutoLogin.exe

   配置和日志都保存在 exe 旁边。放好之后就不要再挪动它了：
   挪走以后「开机自启」还指着老路径，得重新装一次。

2) 双击 UESTC-AutoLogin.exe。

   如果 Windows 弹出蓝色的 SmartScreen 提示「Windows 已保护你的电脑」
   或者「未知发布者」：这是因为 exe 没有花钱买代码签名证书，属于正常现象。
   点「更多信息」->「仍要运行」就过去了。

   （如果双击后窗口一闪就没了：在 exe 所在文件夹的地址栏里输入 cmd 回车，
     然后敲 UESTC-AutoLogin.exe 回车，报错信息就留在窗口里了。）

3) 第一次运行会自动生成 config.toml，并用记事本打开它。
   把它改成你自己的信息，保存（Ctrl+S）后关掉记事本：

       [account]
       username = "你的学号"      <- 改成你的学号，引号保留
       password = "你的密码"      <- 改成你的密码，引号保留
       domain   = "@dx"           <- 网络提供商

   domain 怎么选：
       电信宽带        @dx
       移动宽带        @cmcc
       校园网（主楼）  @dx-uestc

   [portal] 里的 url / ac_id 一般不用改：
       寝室公寓      http://10.253.0.235   ac_id = 3
       主楼有线校园网 http://10.253.0.237   ac_id = 1

   怎么确认 url 和 ac_id：断网后打开浏览器，会自动跳到认证页面，
   把地址栏里的地址抄下来，形如
       http://10.253.0.235/srun_portal_pc?ac_id=3&theme=pro
   其中 10.253.0.235 是 url，ac_id 后面的 3 就是 ac_id。

回到菜单选 1（登录一次），看到
       The loggin result is: ok
就说明配置没问题了。


----------------------------------------------------------------------
二、菜单里都是什么
----------------------------------------------------------------------

   1) 登录一次          试一下配置对不对，成功就退出
   2) 常驻重连          前台一直跑，断线自动重连；按 Ctrl+C 退出。
                        想手动挂机就用这个，关掉窗口就停止重连
   3) 安装开机自启      开机就跑，不用登录 Windows（需要管理员，会弹授权）
   4) 卸载开机自启      把上面那个计划任务删掉
   5) 查看开机自启详情  看任务状态、下次运行时间、启动命令
   6) 登录后自启        用「启动文件夹」实现的自启，不需要管理员，二选一
   7) 编辑 config.toml  改学号密码、换运营商、换认证地址
   8) 打开日志目录      出问题先看这里
   0) 退出


----------------------------------------------------------------------
三、两种「开机自启」的区别（选一个就行，别都装）
----------------------------------------------------------------------

   方式                什么时候启动          需要什么
   ------------------  --------------------  --------------------------
   3) 开机自启         开机 30 秒后自动跑    安装时点一次管理员授权
   （计划任务）        不用登录 Windows       （不保存你的 Windows 密码）

   6) 登录后自启       登录 Windows 之后      什么都不用，双击即可
   （启动文件夹）

   校园网认证是按机器 IP 做的，不依赖桌面，所以推荐用「3) 开机自启」：
   电脑开机后无人值守也会自己连上。卸载时选 4 就行。

   注意：两种都装的话，每次登录会多起一个守候进程，二选一就好。

   开机自启模式下没有可见的窗口，登录结果写在
       logs\always_online.console.log


----------------------------------------------------------------------
四、常见问题
----------------------------------------------------------------------

Q: 双击没反应 / 一闪而过？
A: 说明程序启动时出错了。在 exe 所在文件夹的地址栏输入 cmd 回车，
   再运行 UESTC-AutoLogin.exe，就能看到错误信息。

Q: 提示「Windows 已保护你的电脑」/「未知发布者」？
A: 点「更多信息」->「仍要运行」。exe 没有代码签名，不影响使用。

Q: 忘记放哪了 / 换了文件夹？
A: config.toml 和 logs 都在 exe 旁边，整个文件夹一起搬过去即可。
   搬完记得重新装一次开机自启（菜单 4 卸载、3 安装）。

Q: 报 Failed to resolve IP 或者 Cannot find local ip in login page html？
A: 认证页面地址填错了（url / ac_id）。用浏览器打开认证页核对一下。
   学校如果改了认证页，也要跟着改。

Q: 登录成功但马上又掉线？
A: domain 填错了。电信 @dx、移动 @cmcc、校园网 @dx-uestc，换一个试。

Q: 日志里一直刷 offline，但其实能正常上网？
A: monitor.test_ip 那个 IP 在你的网络里 ping 不通，程序就误判成断线，
   于是反复重试登录。换一个能 ping 通的：
       223.5.5.5（阿里）、119.29.29.29（腾讯）、114.114.115.115
   实测 UESTC 网络里 114.114.114.114 不通，默认用的是 223.5.5.5。

Q: 怎么确认到底登没登上？
A: 三种办法：菜单 1 手动登一次（窗口里会打印 The loggin result is: ok）；
   看 logs\always_online.console.log；或者看 logs 里当天的 .log 是否还在刷
   offline，不刷了说明在线。

Q: 杀毒软件报毒？
A: PyInstaller 打包的单文件 exe 经常被误报（因为它是自解压的）。
   加白名单即可。不放心的话可以自己从头构建：见仓库 README 的「打包与发版」。


----------------------------------------------------------------------
五、卸载
----------------------------------------------------------------------

1) 打开程序 -> 4，卸载开机自启（装过计划任务的话）
2) 打开程序 -> 6 -> 2，卸载「登录后自启」（装过的话）
3) 删除整个文件夹（exe、config.toml、logs）即可，不写注册表、不留后台服务。


----------------------------------------------------------------------
六、安全提醒（重要）
----------------------------------------------------------------------

config.toml 里是你的学号和密码明文。请不要：

  * 把 config.toml 发给别人，或者截图发出去；
  * 把带 config.toml 的文件夹上传到网盘 / GitHub。

要分享给同学，只发 UESTC-AutoLogin.exe 这一个文件（还有这份说明），
他自己填自己的账号就行。仓库里也只有 config.example.toml 这个空模板。
